# Zdorovo Dental — документація

Інструкції для адміністратора сайту [zdorovo-dent.com.ua](https://www.zdorovo-dent.com.ua) —
як наповнювати й обслуговувати сайт. Оформлено за фірмовою дизайн-системою бренду.

## Як користуватися

Відкрийте **[`index.html`](index.html)** — це головна сторінка з посиланнями на всі інструкції.
Кожен гайд доступний як веб-сторінка (`.html`) і як файл для друку (`.pdf`).
